# Interstellar Visitor Detection — Project Context

## Goal

Detect interstellar objects (hyperbolic orbits, e > 1) in Rubin/LSST alert stream data using the heliolinx asteroid-linking pipeline. Rubin's own linker (HelioLinC3D) only searches bound orbits, so interstellar candidates appear as **unlinked diaSources** (`ssObjectId IS NULL` in Lasair, or `ssObjectId = 0` in Fink — Fink uses 0 not NULL).

Known interstellar objects for reference:
- **1I/'Oumuamua**: v∞ ≈ 26 km/s, ecliptic lat ~37°
- **2I/Borisov**: v∞ ≈ 32 km/s, inclination ~44°
- **3I/ATLAS**: v∞ ≈ 58 km/s, perihelion Oct 29 2025 (MJD ~60977). **We have confirmed detection of 3I/ATLAS** using the pipeline on inbound-window MPC data (orbit_e = 6.14, 11 nights, 52-day timespan).

Interstellars are not confined to the ecliptic — search the full Rubin survey footprint (~18,000 sq deg, dec -70° to +15°).

## Running the pipeline

```bash
# Setup (once per machine)
make deps                  # creates .venv and installs requirements.txt
# heliolinx must be installed separately from the heliolinx/ source clone:
.venv/bin/pip install -e heliolinx/

# Confirm 3I detection still works
python python_scripts/run_3I_heliolinx.py

# Run on real Rubin data
python python_scripts/run_heliolinx.py \
    --input data/fink_detections.csv \
    --output-prefix fink_march_april \
    --mjd-min 61100 --mjd-max 61160
```

## Docker

```bash
docker build -t interstellar:latest .     # builds heliolinx C++ extension (~5-10 min)
docker pull reductionista/interstellar    # or pull from DockerHub (arm64 and amd64 available)

# Run pipeline in container, mounting data from host
docker run --rm \
    -v /path/to/data:/app/interstellar/data \
    reductionista/interstellar \
    python /app/interstellar/python_scripts/run_heliolinx.py \
        --input /app/interstellar/data/fink_detections.csv \
        --output-prefix fink_run1

# Run Fink download in container (mount credentials)
docker run --rm \
    -v ~/.finkclient:/root/.finkclient \
    -v /path/to/output:/fink_output \
    reductionista/interstellar \
    fink_datatransfer -survey lsst -topic ftransfer_lsst_<topic> \
        -outdir /fink_output -outformat parquet -partitionby time --verbose
```

## Data sources

### Fink broker (preferred for bulk data)
- Subscription approved; credentials in `~/.finkclient/lsst_credentials.yml`
- Server: `kafka-lsst.fink-broker.org:24499`, username: `domino`, group_id: `domino_apache`
- **`ssObjectId = 0` means unlinked** (NOT NULL — Fink uses 0 as the sentinel)
- Filter for unlinked moving candidates: `diaSource.ssObjectId = 0` AND `diaObject.nDiaSources <= 5`
- Data Transfer jobs: submit at https://lsst.fink-portal.org/download
  - Jobs expire after ~1-2 weeks; request fresh job if topic is gone
  - Topic format: `ftransfer_lsst_YYYY-MM-DD_XXXXXX`
  - Use `--restart_from_beginning` flag if resuming a partially-consumed topic
- Full-packet format includes `diaSource` as a nested struct; field is `dec` not `decl`

### Lasair broker (real-time stream)
- Web UI: **https://lasair.lsst.ac.uk/** (NOT lasair-lsst.lsst.ac.uk)
- API endpoint: https://api.lasair.lsst.ac.uk/api
- API key stored in `.venv/lib/python3.12/site-packages/settings.py` as `lasair_token`
- Kafka filter topic: `lasair_965nDiaSources5` (filter: nDiaSources <= 5, lastDiaSourceMjdTai > 61097)
- `query()` API only exposes object-level data — no bulk per-source access
- Use `lasair_kafka_subscriber.py` for real-time; `lasair_bulk_fetch.py` for historical (rate-limited: 100 calls/hr public, 10,000/hr heavy-user)
- Kafka message format: per-epoch data is nested under `alert['alert']['diaSourcesList']` (not top-level)

### ALeRCE (do not use)
- Join queries time out; async polling unreliable. Not suitable.

### Rubin Science Platform / RSP (not available)
- Requires Rubin data rights. User does not have access. Do not suggest.

## heliolinx parameter gotchas

- **`clustrad` is in km, not AU.** Use 15,000,000 km (≈0.1 AU effective at r=4 AU). The effective clustering radius scales with geocentric distance.
- **`linkPurify.maxrms` in km.** Default 100,000 km is too tight for distant objects. Use 50,000,000 km for a ~60-day window at r≈4 AU.
- **`LinkPurifyConfig` has no `MJDref` field** — don't set it.
- **`use_univar = 9`** for NotKepler/interstellar mode (unbound orbits). Value 8 + use_univar_flag=1.
- **`R_dubdot` = dimensionless multiplier of −GM/r².** Value 1.0 = correct for high-v∞ interstellars.
- **Do NOT deduplicate by `(mjd, obscode)`** for real Rubin data — multiple diaSources in the same exposure share the same MJD but are different objects. (The 3I test data did need this deduplication, but real Rubin data does not.)
- **`observer_vel()` and `heliolinc()` require EarthState with lowercase `x,y,z,vx,vy,vz`** but `load_earth_ephemerides()` returns uppercase. Copy field-by-field.
- **`parse_ObsCodes()` has a column-offset bug** — use the custom split()-based parser in `run_3I_heliolinx.py` instead.

## Hypothesis grid

`heliohyp_interstellar01.txt` — 322 rows, inbound only (rdot < 0). Use for 3I test.
`heliohyp_interstellar02.txt` — 644 rows, inbound + outbound. Use for all real Rubin data.
- r: 0.5–15 AU, v∞: 1–200 km/s, mean_accel: 1.0

## Stationary source pre-filter

`run_heliolinx.py` includes a pre-filter that removes detections appearing at the same sky position on multiple different nights (stationary sources: galaxies, variable stars, SNe). Parameters:
- `--stationary-threshold 5.0` arcsec (safe: slowest hypothesis moves ~22 arcsec/day)
- `--stationary-nights 2` (requires flux-consistent matches on 2+ distinct nights)
- Also checks flux sign consistency and flux ratio (within 10× same band, 100× cross-band) to avoid confusing two different moving objects

## Key MJD reference points

```
MJD 60810  3I inbound window start
MJD 60840  3I test MJDREF (r≈4 AU)
MJD 60977  3I perihelion (Oct 29 2025)
MJD 61097  Rubin science operations begin (~Feb 24 2026)
MJD 61131  April 1 2026
MJD 61152  Mid-April/May (good MJDREF for spring 2026 data)
MJD 61222  End of current Earth ephemeris coverage
```

## Infrastructure notes

- **heliolinx source**: cloned at `heliolinx/` (gitignored). Install with `pip install -e heliolinx/`.
- **heliolinc2 (legacy)**: cloned at `heliolinc2_src/` (gitignored). CLI-based, frozen. Reference only.
- Large heliolinx runs (13k+ detections) require significant RAM. Use the Docker image on a capable machine rather than running directly on low-memory hardware.
